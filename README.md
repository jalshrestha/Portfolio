# Jaljala's Portfolio Website

A professional portfolio website showcasing my projects, skills, and blog.

## Features

- **Home Page**: Introduction and overview of skills
- **Projects Section**: Showcase of key projects including:
  - Audio Notes Voice Recording App
  - NBA Stats Dashboard
  - Stock Analysis and Price Prediction
- **Blog**: Articles on tech topics with a focus on physics, AI, trading, and consciousness
- **Interactive Design**: Dynamic particle backgrounds and hover effects
- **Responsive Layout**: Optimized for various screen sizes

## Technologies Used

- HTML5, CSS3, JavaScript
- Webpack for bundling
- Particles.js for animated backgrounds
- Python HTTP server for local development

## Setup and Installation

1. Clone this repository
2. Navigate to the project directory
3. To run locally: `python -m http.server 8000`
4. Visit `http://localhost:8000` in your browser
